# plus-smart-home-tech


## Проект по обеспечению пользователей умными устройствами: сервисы для обработки показаний датчиков и интернет магазин для управления поставками оборудования


### Описание
Проект состоит из двух основных частей:
* телеметрия: сбор и обработка показаний датчиков
* backend интернет магазина оборудования

#### Телеметрия
Состоит из трех компонентов.

**Collector**. Выступает в роли шлюза: принимает трафик от различных "умных домов", переупаковывает сырые данные в 
бинарный формат Avro и публикует их в Kafka, выступая источником событий для других компонентов системы.  
**Aggregator**. Подписан на поток данных от датчиков в Kafka. Служит вычислителем состояний: группирует входящие события 
по хаб-идентификаторам и записывает обратно в Kafka целостные снимки обстановки для каждого объекта.  
**Analyzer**. Сканирует агрегированные снимки состояний. Выступая в роли триггера, сравнивает их с библиотекой сценариев.
При обнаружении нужной комбинации передает управляющий сигнал на исполнение к конкретному "умному дому".

#### Backend интернет магазина оборудования
Состоит из нескольких компонентов, взаимодействие c которыми осуществляется через единый Gateway. Между собой сервисы 
взаимодействуют через REST API.

* **Витрина товаров** — управляет каталогом: отображает карточки товаров, цены и характеристики, позволяя пользователям 
изучать ассортимент.  
* **Оформление заказов** — занимается созданием заказов на основе содержимого корзины, сохраняет детали покупки и статусы
выполнения.
* **Корзина покупателя** — отвечает за наполнение корзины: добавление и удаление позиций, изменение количества выбранных 
товаров.
* **Оплата заказов** — обрабатывает финансовые транзакции, взаимодействует с внешними платёжными системами и подтверждает
факт оплаты.
* **Складской учёт** — контролирует наличие товаров, резервирует позиции при заказе и обновляет остатки после отгрузки.   
* **Доставка товаров** — координирует передачу заказов в службы доставки, отслеживает перемещение грузов и уведомляет 
клиентов о статусе.

* Hibernate
* Maven
* Docker


### Техническое описание
Проект состоит из трех модулей:
* **telemetry** - телеметрия
* **commerce** - backend интернет магазина оборудования
* **infra** - Spring Cloud: конфигурирование и связь между сервисами

Модуль **commerce** построен по принципу `Database per Service`.
